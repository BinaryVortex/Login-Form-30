# Login Form (HTML/CSS/JavaScript)

Login Form built using HTML, CSS and JavaScript.

![Login Form Screenshot](./Screenshot%202024-07-02%20095634.png)

## Overview

A clean, responsive login form built with plain HTML, CSS and a bit of JavaScript. This repository contains a single-page example you can open in any modern browser. The layout focuses on accessibility, a modern look, and simple interactions.

Languages: HTML, CSS (majority CSS styling)

## Features

- Lightweight single-page login form
- Responsive layout for desktop and mobile
- Customizable styling (style.css)
- Minimal JavaScript for form interactions/validation

## Files

- `index.html` — The form markup
- `style.css` — Styling and layout
- `Screenshot 2024-07-02 095634.png` — Preview image shown above

## Usage

1. Clone or download this repository:

   git clone https://github.com/BinaryVortex/Login-Form-30.git

2. Open `index.html` in your browser (double-click or use a local server).

3. Edit `style.css` or `index.html` to customize the look and behavior.

## Customization tips

- Change colors and spacing in `style.css` to match your design.
- Replace the logo/heading text in `index.html`.
- Add real authentication by wiring the form to a backend endpoint (this sample only demonstrates front-end behavior).

## Browser support

Works in modern browsers (Chrome, Firefox, Edge, Safari). No build tools or dependencies required.
